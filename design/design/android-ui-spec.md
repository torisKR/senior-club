# 안드로이드 UI/UX 규격서 — 청솔 시니어 마을

> **Status**: APPROVED · 2026-11-05
> **기준 해상도**: 360×800dp 세로 · Android 8.0+ · 한 손 엄지 조작
> **연관**: `design/art/art-bible.md` §7·§10 · `design/gdd/android-game-plan.md` §8

이 문서는 화면을 만들 때 매번 판단하지 않도록, **레이아웃·타이포·상태·모션**을 수치로 고정합니다.

---

## 1. 화면 지도와 진입

| 화면 | 경로 | 역할 | 진입 |
|------|------|------|------|
| 마을 | `/home` | 기본 허브. 이동·NPC·루틴·막 진행 | 앱 시작 |
| 프롤로그 | (모달) | 최초 1회 3장 서사 | 마을 최초 진입 |
| 튜토리얼 배너 | (오버레이) | 이동 → 체조 → 파크골프 3단계 | 프롤로그 종료 후 |
| 파크골프 | `/clubs` | 1홀 퍼팅 | 하단 탭·시설 |
| 알까기 | `/events` | 1대국 | 하단 탭·시설 |
| 사천성 | `/chat` | 1판 | 하단 탭·시설 |
| 명인전당 | `/me` | 급수 계보·전적·설정 | 하단 탭 |

- 하단 탭 5개: 라운지 · 파크골프 · 알까기 · 사천성 · 명인전당.
- 뒤로가기: 탭 루트에서는 **종료 확인**, 하위 화면은 이전 화면. 모달은 뒤로가기로 닫힘.
  구현: `use-android-back-exit.ts`(홈 탭 포커스 시에만 등록) + `exit-confirm-dialog.tsx`.
  확인 다이얼로그가 열린 상태에서 뒤로가기를 한 번 더 누르면 취소로 처리합니다.

## 2. 레이아웃 그리드

```
┌─────────────────────────────┐ 360dp
│ 상태바 인셋 (safe-area.top)  │
├─────────────────────────────┤
│ 상태 명판 (HP·EXP·CP·급수)   │ 96dp
├─────────────────────────────┤
│ 콘텐츠 (스크롤 가능)          │ 가변
│  · 마을 뷰포트 440dp         │
│  · 카드 간격 12dp            │
├─────────────────────────────┤
│ 하단 탭 (60dp + safe-area)   │
└─────────────────────────────┘
```

- 좌우 여백 **16dp**, 카드 내부 **16dp**, 카드 간 **12dp**.
- 모든 주요 버튼 높이 **≥56dp**, 보조 칩 **≥48dp**, 버튼 간 최소 **12dp**.
- 드래그·조작 영역과 광고 배너 사이 **≥24dp** 완충.

## 3. 타이포그래피

| 역할 | 크기 | 굵기 | 용도 |
|------|------|------|------|
| 결과 타이틀 | 32~36pt | ExtraBold | 홀인·승리·승급 |
| 핵심 수치 | 28~32pt | ExtraBold, tabular | CP·타수·남은 알 |
| 카드 제목 | 22~24pt | SemiBold | 시설·모드 |
| 본문 | 18~20pt | Regular | 대사·설명 |
| 보조 라벨 | 16pt | SemiBold | 단위·힌트 |

- 큰 글씨 모드: 본문 +2pt, 행간 +4dp. 말줄임(`...`)으로 숫자를 가리지 않는다.
- 픽셀 아트 배지·아이콘 위에 텍스트를 얹지 않는다(가독성 우선).

## 4. 색과 대비

| 역할 | 토큰 | 값 | 대비 |
|------|------|----|------|
| 배경 | `surface` | `#FCF9F2` | — |
| 본문 | `text` | `#182620` | 14:1 |
| 주요 버튼 | `primary` | `#0E5142` | 8.9:1 (흰 글자) |
| 강조 CTA | `accent` | `#C2410C` | 5.6:1 (흰 글자) |
| 보상·금빛 | `gold` | `#F0BF4F` | 어두운 배경 위 8:1 |
| 비활성 | `textSecondary` | `#5B6B62` | 4.6:1 |

- 상태는 **색 + 형태 + 텍스트** 3중으로 전달한다(색각 이상 대응).
- 다크 모드는 마을·아케이드 화면에서 원목 톤을 유지하도록 별도 팔레트를 쓴다.

## 5. 상태 설계

| 상태 | 화면 처리 | 예시 |
|------|-----------|------|
| 로딩 | 스켈레톤 없이 **큰 스피너 + 안내 문구** | "마을을 준비하고 있어요" |
| 빈 상태 | 다음 행동 1개만 제안 | "아직 기록이 없습니다 · 파크골프 1홀 시작" |
| 오프라인 | 상단 1줄 배너, 플레이는 그대로 | "오프라인 플레이 중 · 기록은 기기에 저장됩니다" |
| 저장 실패 | 조용히 재시도, 플레이 유지 | 콘솔 경고만 |
| 권한 거부 | 기능만 비활성, 재요청은 설정에서 | 알림 끔 |
| 실패(게임) | 같은 화면에서 재시도 + 소량 보상 | "다시 한 번" |

## 6. 모션

| 동작 | 길이 | 이징 |
|------|------|------|
| 화면 전환 | 200ms | ease-out |
| 모달 등장 | 240ms | ease-out |
| 카드 눌림 | 90ms | linear |
| 승급 폭죽 | 3.5s | 12fps 스프라이트 |
| 타격 이펙트 | 1.0s | 14fps 스프라이트 |
| 화면 흔들림 | 120ms, 3px 이내 | 알까기 일석이조만 |

- `prefers-reduced-motion` 상당의 **모션 줄이기** 설정을 둘 경우 이펙트는 1회만 재생하고 정지한다.
- 이펙트는 항상 `pointerEvents="none"` 으로 조작을 막지 않는다.

## 6.1 동행·코치 UI

| 요소 | 위치 | 규격 |
|------|------|------|
| 동행 카드 | 마을 상단, 스토리 배너 아래 | 초상화 56dp, 유대 게이지 8dp, 버튼 2개(산책 마치기/헤어지기) |
| 산책 말풍선 | 동행 NPC 머리 위 | 폭 168dp, 최대 2줄, 4.2초 후 자동 사라짐, `pointerEvents: none` |
| 코치 패널 | 미니게임 상단, 보드 위 | 초상화 44dp, 1~2줄 대사, 유대 2단계부터 힌트 1줄 |
| 유대 게이지 | 동행 카드·기록 카드 | 금빛 `#F0BF4F`, 트랙 `#EFE3C8` |
| 마음 온도 | 기록 카드 | 0~100, 황토 `#C2410C` |

- 말풍선·코치 패널은 조작을 가리지 않습니다. 보드는 항상 화면 중앙, 패널은 상단 고정.

## 7. 오디오·햅틱

| 순간 | 소리 | 진동 |
|------|------|------|
| 버튼 | 짧은 클릭 | light |
| 퍼팅 | 나무 타구음 | medium |
| 홀인 | 차임 | success |
| 알까기 충돌 | 돌 부딪힘 | medium |
| 일석이조 | 가야금 콤보 | success |
| 승급 | 차임 + 폭죽 | success |

- 설정에서 소리·진동을 각각 끌 수 있고, 끈 상태는 저장된다.
- 앱이 백그라운드로 가면 BGM은 즉시 정지한다.

## 8. 픽셀 아트 표시 규칙

- 1 아트픽셀 = 1dp, 런타임 PNG는 3배 최근접 업스케일(`design/art/pixel-art-pipeline.md`).
- 캐릭터·타일은 1:1, 이펙트는 1dp/아트픽셀로 그린다.
- 이미지에 `image-rendering: pixelated` 상당 처리를 위해 확대 배율을 정수로 유지한다.
- 아이콘과 텍스트를 겹칠 때는 아이콘 뒤에 단색 원형 배경을 둔다.

## 9. 접근성 체크리스트

- [ ] 모든 터치 타깃 ≥48dp, 주요 버튼 ≥56dp
- [ ] 본문 대비 ≥4.5:1, 큰 텍스트 ≥3:1
- [ ] 색만으로 상태를 구분하지 않음
- [ ] 스크린리더 라벨: 아이콘 버튼은 동작을 문장으로
- [ ] 큰 글씨 130~150%에서 줄바꿈·말줄임 확인
- [ ] 모달은 포커스 트랩 + 뒤로가기로 닫기
- [ ] 애니메이션은 조작을 가리지 않음
