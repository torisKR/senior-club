# 안드로이드 앱 게임 기획서 — 청솔 시니어 마을

> **Status**: APPROVED · 2026-11-05
> **선행 문서**: `design/gdd/game-concept.md` · `design/story/story-bible.md` · `design/design/android-ui-spec.md`
> **빌드 기준**: Expo SDK 57 · React Native 0.86 · Android 8.0+ · 세로 360×800 기준 · 오프라인 퍼스트(SQLite)

이 문서는 "시니어 클럽: 아케이드 라운지"를 **안드로이드 앱 게임**으로 출시하기 위한 기획 기준선입니다.
마을 RPG(탐험·생활·성장)와 3대 종목(파크골프·알까기·사천성)을 하나의 3분 루프로 묶는 것이 목표입니다.

---

## 1. 한 문장 정의

> **은퇴 후 청솔마을에 입주한 18급 신입 회원이, 아침 체조와 세 가지 전통 놀이를 통해
> 클럽 명인(名人)까지 성장하는 세로형 픽셀 아트 생활 RPG.**

## 2. 타깃과 플레이 환경

| 항목 | 기준 |
|------|------|
| 주 사용자 | 50~70대, 하루 1~3회, 회당 3~10분 |
| 손 | 한 손 엄지 조작. 모든 핵심 동작은 화면 하단 1/3 안에서 끝난다 |
| 눈 | 큰 글씨 모드 지원. 최소 본문 18pt, 핵심 수치 28pt 이상 |
| 기기 | Android 8.0+, 360×800 논리 해상도, 2GB RAM 이상 |
| 네트워크 | **없어도 플레이 가능**. 저장·진행·보상 전부 로컬 SQLite |
| 세션 | 앱을 닫아도 마지막 위치와 판 상태에서 즉시 이어하기 |

## 3. 핵심 루프 4단

| 루프 | 길이 | 내용 | 보상 |
|------|------|------|------|
| **즉각 루프** | 3~20초 | 방향 버튼 이동, NPC 대화, 체조·약 복용 탭 | 활력(HP), 연륜(EXP), 안내 문구 |
| **한 판 루프** | 2~3분 | 파크골프 1홀 / 알까기 1대국 / 사천성 1판 | CP 120~220, 인장 1, 별점 |
| **마을 루프** | 10~15분 | 일일 미션 3종 + 개근 도장 + 방치 시설 수확 | 도토리, 인장, 방치 보상 |
| **관계 루프** | 3~5분 | NPC와 동행 산책 → 함께 한 판 → 회고 | 유대, 마음 온도, 개인 에피소드 |
| **승단 루프** | 3~7일 | CP 누적 → 급수 승급 → 새 막 해금 → 복장 변화 | 명패, 스토리 막, 시설 해금 |

## 4. 성장 곡선 (CP ↔ 급수)

| 급수 | 필요 CP | 한 판 평균 CP | 필요 판수(누적) | 대응 막 | 복장 |
|------|---------|---------------|-----------------|---------|------|
| 18급 신입 | 0 | — | 0 | 1막 | 베이지 |
| 15급 회원 | 200 | ~150 | 2 | 2막 | 베이지 |
| 12급 숙련 | 500 | ~160 | 4 | 3막 | 베이지 |
| 9급 유단자 | 900 | ~170 | 6 | 4막 | **청자** |
| 5급 상급 | 1,400 | ~180 | 9 | 5막 | 청자 |
| 1급 고수 | 2,000 | ~190 | 12 | 6막 진입 | 청자 |
| 초단(初段) | 2,700 | ~200 | 15 | 6막 중반 | 청자 |
| 클럽 명인 | 3,500 | ~210 | 19 | 6막 완수 | **상아·먹색** |

- 한 판 CP: 파크골프 120(파 초과)/180(파 이하), 알까기 160+일석이조 50, 사천성 170+콤보×10.
- **신규 설치는 반드시 0 CP(18급 신입)에서 시작**합니다. 기존 세이브는 저장값을 그대로 승계합니다.
- 승급은 자동이며, 승급 순간 pixelfx 폭죽과 명패 갱신이 함께 나옵니다.
- 막 진행은 `다음 막 minCp` 게이트로 잠기고, 부족하면 남은 CP를 안내합니다.

## 5. 난이도와 실패 처리

| 종목 | 난이도 축 | 실패 시 | 피티(pity) 규칙 |
|------|-----------|---------|-----------------|
| 파크골프 | 홀별 par, 경사·바람, 3단 파워 | 같은 홀 재시도, 기록만 남김 | 3회 연속 par 초과 시 조준 가이드 강조 |
| 알까기 | 상대 급수(18급/9급/명인), 파워 3종 | 재대국, 승리 기록 없음 | 2연패 시 상대 알 1개 감소 |
| 사천성 | 8×6 그리드, 2회 굴절 | 같은 판 리셋 | 3회 막힘 시 돋보기 1개 지급 |

- **시간 제한 없음.** 초시계로 실수를 유도하지 않습니다(게임 컨셉 Pillar 4).
- 실패 화면에서도 보상(경험·도토리 소량)을 주어 "한 판 더"의 이유를 만듭니다.

## 5.1 관계 성장 (유대)

- NPC 5인과 각각 유대 0~5단계(0/20/50/90/140/200).
- 획득: 하루 첫 산책 +15, 그 NPC와 함께 한 판 +8, 차·선물 +10(하루 1회).
- 단계 보상: 동행 해금 → 코치 힌트 → 개인 에피소드 → 소품 변화 → 명인전 추천사.
- **공정성**: 유대는 판정·확률·보상 수치를 바꾸지 않습니다. 대사·기록·연출만 엽니다.
- 하루 상한이 있어 "숙제"가 되지 않습니다. 실패·결석 패널티 없음.

## 6. 리텐션 설계

| 장치 | 주기 | 보상 | 이탈 방지 효과 |
|------|------|------|----------------|
| 일일 미션 3종 | 매일 00:00 리셋 | 인장, 도토리 | "오늘 할 일이 남았다" |
| 개근 도장 | 매일 1회 | 명예 인장 | 연속 방문 습관 |
| 방치 시설 | 오프라인 누적 | 도토리·연륜 | 복귀 보상(최대 8시간) |
| 6막 승단 서사 | 급수 도달 시 | 새 막·복장 | 장기 목표 |
| 프롤로그·튜토리얼 | 최초 1회 | 첫 도토리 주머니 | 초기 이탈 방지 |

- 오전 9시 아침 체조 알림은 향후 검토 항목입니다. 현재 게임에서는 푸시 알림을 발송하지 않습니다.
- 방치 보상은 복귀 시 모달로 1회 지급합니다. 두 배 보상 광고는 검증 전까지 제공하지 않습니다.

## 7. 수익화 경계

> 2026-11-06: 아래 표는 이전 구성의 기록입니다. 새로운 광고·꾸미기 방향과 현재 확인된 구현 상태는 `game-monetization-proposal.md`를 따릅니다. 상품과 가격은 아직 확정하지 않았습니다.

| 상품 | 가격 | 효과 | 공정성 |
|------|------|------|--------|
| 하단 배너 광고 | 무료 | 홈/라운지 하단에만 | 조작 영역과 24dp 이상 분리, 플레이 중 미노출 |
| 시니어클럽 플러스 | 4,900원 1회 | 배너 제거 + 명인 금장 배지 스킨 | **판정·확률·보상에 영향 없음** |

- 결제는 AAB 업로드 이후 상품 생성이 가능하므로, 출시 순서는 `광고만 → 검증 → 플러스 활성`입니다.
- 확률형 뽑기·에너지 게이팅·광고 강제 시청은 넣지 않습니다.

## 8. 안드로이드 앱 게임 요구사항

| 영역 | 요구 | 구현 상태 |
|------|------|-----------|
| 화면 | 세로 고정, 상단 상태바·하단 내비게이션 인셋 대응 | `Screen` 공통 컴포넌트 + safe-area |
| 뒤로가기 | 탭 루트에서는 앱 종료 확인, 하위 화면은 복귀 | **완료** — 홈에서 `BackHandler` + 종료 확인 다이얼로그, 다른 탭은 Expo Router 기본 |
| 생명주기 | 백그라운드 진입 시 저장, 복귀 시 오프라인 정산 | `useFocusEffect` + SQLite 저장 |
| 저장 | 모든 진행 로컬, 실패해도 게임 속행 | `expo-sqlite` KV + 메모리 폴백 |
| 성능 | 60fps 목표, 화면당 텍스처 2장 이하, 전환 160~240ms | 픽셀 에셋 3x, 이펙트 시트 1장 |
| 접근성 | 56dp 터치, WCAG AA 4.5:1, 큰 글씨 130~150% | 테마·컴포넌트 공통 규칙 |
| 권한 | 알림(선택), 진동. 위치·연락처·사진 요청 없음 | 매니페스트 검증 스크립트 |
| 오프라인 | 비행기 모드에서 전체 플레이 가능 | 로컬 전용 루프 |

### 8.1 뒤로가기 동작 (구현 완료)

- 홈 탭이 **포커스일 때만** `BackHandler`를 등록합니다(`useAndroidBackExit`).
  다른 탭에서는 Expo Router의 기본 뒤로가기를 그대로 씁니다.
- 뒤로가기 → **"게임을 종료할까요?"** 다이얼로그. 버튼은 `계속하기`(기본) / `종료하기`.
- 다이얼로그가 열린 상태에서 뒤로가기를 한 번 더 누르거나 `계속하기`를 누르면 닫힙니다.
- `종료하기`를 확정했을 때만 `BackHandler.exitApp()`을 호출합니다.
- iOS/웹에서는 리스너를 등록하지 않습니다.
- 상태 전이는 순수 리듀서(`src/rpg/back-exit.ts`)로 분리해 5개 테스트로 고정했습니다.

## 9. 화면 지도

```
[앱 시작]
  └─ /home  마을 (기본 탭)
       ├─ 프롤로그 모달 (최초 1회, 3장)
       ├─ 튜토리얼 배너 (이동 → 체조 → 파크골프)
       ├─ /clubs  파크골프
       ├─ /events 알까기
       ├─ /chat   사천성
       └─ /me     명인전당 (급수 계보·전적·설정)
```

- 튜토리얼은 **강제 차단이 아니라 배너**입니다. 언제든 "건너뛰기"로 닫을 수 있습니다.
- 프롤로그는 3장 이내, 한 장당 2문장 이내. 큰 글씨 모드에서도 스크롤 없이 보입니다.

## 11. 범위

**이번 릴리스 포함**
- 마을 탐험·생활 루틴, 3대 종목, 6막 승단 서사, 프롤로그·튜토리얼, 오프라인 저장, 배너+플러스.

**명시적 제외**
- 실시간 멀티플레이, 길드/채팅, 시즌 랭킹, 클라우드 세이브, 태블릿 전용 레이아웃, iOS 최적화.

## 12. 리스크와 대응

| 리스크 | 영향 | 대응 |
|--------|------|------|
| 작은 글씨로 초기 이탈 | 높음 | 큰 글씨 모드 기본 노출, 18pt 하한, 튜토리얼 문장 30자 이내 |

| 스토리 급수와 실제 CP 불일치 | 중간 | 신규 기본 CP 0 + 막 게이트 검증 테스트 |
