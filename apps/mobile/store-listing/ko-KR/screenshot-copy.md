# Google Play 휴대전화 스크린샷 문구

첫 세 장에 탐색, 신청, 관계 형성의 핵심 가치를 배치한다. 문구는 캡처 위에
결정론적으로 합성하고 실제 앱 UI를 가리지 않도록 이미지 면적의 20% 이내로 둔다.

1. 관심사로 내게 맞는 모임을 한눈에
2. 날짜·장소·난이도를 보고 편하게 신청
3. 참여자와 채팅으로 함께 준비
4. 신청·승인 상태를 분명하게 확인
5. 함께한 활동을 후기로 기록
6. 등산·사진·원예, 좋아하는 주제로 시작

권장 순서: 홈 → 모임 탐색/상세 → 신청 상태 → 채팅 → 후기 → 관심사.
로그인 화면은 실제 프로덕션 인증이 연결된 이후에만 등록정보에 사용한다.
