# 시니어클럽 실기기 검증 기록

## 이동 중 프레임 표본

`dumpsys gfxinfo ... framestats`에서 이동 중 최근 약 120개 완료 프레임을 수집했다. 아래 값은 프레임의 예정 Vsync부터 완료까지의 시간이며 평균 FPS가 아니다. 표본은 짧고 출발 위치, 이동 경로, 온도가 정확히 통제되지 않아 개선 폭을 인과관계로 확정할 수 없다. 16.67ms 초과 수는 60Hz 예산 기준의 단순 비교이며 기기의 실제 재생률이나 장시간 안정성 판정이 아니다.

기기 배터리 온도는 초기 25.3°C, 후반 31.8°C로 관찰됐으나 충전 중이고 작업 시간과 환경이 통제되지 않아 발열 비교 결과로 해석할 수 없다.

## 위 캡처 이후의 로컬 변경

사용자가 QA 테스트 생략을 요청한 뒤에는 새 기기 플레이나 성능 측정을 하지 않았다. 위 스크린샷과 수치는 다음 변경을 보여 주지 않으며, 현재 작업 트리의 체감 성능을 증명하지 않는다.

- 입구·수확 표식과 지도 내 건물·사진 명소 안내, 생활 일지와 여러 채집물 선택을 추가했다.
- 동행 이동과 생활 행동 피드백, 낚시 입질 알림, 가구 이동 안내를 보완했다.
- 마을 메뉴에 접근성 설정을 연결하고, 닫힌 창의 내용과 비활성 화면의 타이머·반복 효과를 줄였다.
- 이동 위치 중복 저장을 줄이고, 파크골프 타격 중 중복 입력과 활력이 가득 찼을 때 회복 물품 소비를 막았다. 사천성 힌트는 패판 위치와 패 좌표를 안내한다.
- 걷기 프레임 갱신을 주인공 이미지로 분리하고, 흔들릴 장식이 있는 청크에서만 바람 애니메이션을 사용한다. 채집물 배치 후보는 한 번의 지도 순회로 모은다.
- 채집물과 물가·장애물 경계의 시각 대비를 조정하고, 가까운 선착장 안내와 지도 내 생활 활동 방향을 추가했다. 이 표시가 실제 화면에서 잘 보이는지는 확인하지 않았다.
- 낚시 입질 후 입력 시간을 15초로 늘리고, 입질 표시가 시작된 시점부터 시간을 계산한다. 휴식·사진과 가구 배치에도 피드백을 연결했다.
- 동행 이웃이 버스로 함께 이동하고 마을 메뉴에서 산책 대화를 나눌 수 있도록 했다. 조이스틱 및 아케이드 결과의 스크린리더 안내와 큰 글씨 배치를 보완했다.
- 앱을 켜 둔 채 날짜가 바뀌면 마을과 아케이드 일일 상태를 갱신하고, 저장 보호 재시도 시 미저장 이동 위치를 포함해 다시 쓰도록 했다. 실제 자정 경계와 저장 복원은 확인하지 않았다.
- 지도에 시설 입구와 휴식 장소의 방향을 추가하고, 동행 중인 이웃의 이전 위치는 지도에서 숨겼다. 여러 행동이 겹친 곳에서는 입장과 대화를 각각 고를 수 있다.
- 이웃의 여러 대사를 볼 수 있게 하고 동행 말풍선이 너무 빨리 바뀌지 않도록 했다. 프롤로그와 복귀 보상은 순서대로 표시하며, 집 꾸미기에도 배경 음악을 연결했다.
- 모달 뒤 마을 움직임과 낚시 제한 시간을 일시 정지하고, 일지의 날짜·작물 상태 갱신은 유지한다. 텃밭 성장 경계와 날짜가 바뀐 뒤 일지 초안 처리도 보완했다.
- 파크골프·알까기 조작 안내와 사천성 연속 입력 처리를 보완하고, 이야기 시련 결과가 반영되지 않으면 완료로 단정하지 않도록 했다. 각 화면의 실제 반응은 확인하지 않았다.

이후 일부 변경에 대한 TypeScript와 ESLint 정적 검사는 통과했다. 저장 복원, 구매 권한, 조작감, 접근성, 시각적 겹침과 프레임·발열은 현재 변경분에서 검증되지 않았다. 이 작업에서는 배포를 진행하지 않았다.

## 남은 검증

- 같은 출발점과 경로로 반복하고 장시간 프레임·발열 및 입력 지연을 측정한다.
- 기존 사용자 저장 데이터, 실제 구매 및 광고 제거 권한을 검증한다.
- 코드에서 스토어 미구매가 확인된 경우에만 광고를 허용하도록 보완했다. 스토어 조회 불가나 구매 처리 중에는 광고 요청을 보류하고, 처리 중 조회만으로 저장된 구매 토큰을 지우지 않는다. 실제 구매·복원 및 광고 노출 여부는 확인하지 않았다.
- 구매 작업이 진행 중일 때 들어온 소유권 재조회 요청은 즉시 처리되지 않고 별도로 대기열에 남지 않는다. 이후 스토어 알림이나 앱 복귀가 없으면 처리 중 구매의 상태 반영이 지연될 가능성이 있으며, 실제 결제 흐름에서는 확인하지 않았다.
- 알까기와 사천성 완주, 건물 입구와 장애물 전체, 접근성 설정을 실기기에서 확인한다.
- 기기 ADB 재연결 후 실험용 QA 패키지를 이전 빌드로 복원한다. 기존 설치 앱을 덮어쓰거나 데이터를 초기화하지 않는다.
