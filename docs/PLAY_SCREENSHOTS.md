# Android 게임 스크린샷

시니어클럽의 Play 화면은 최종 소스의 실제 Android 앱에서 캡처한다. 마을과 이야기, 파크골프, 알까기, 사천성, 명인전당 중 플레이어가 실제로 도달할 수 있는 화면을 보여 준다. 생성 이미지나 예전 커뮤니티 화면을 실제 게임 캡처로 사용하지 않는다.

휴대전화는 5~6장, 7인치와 10인치 태블릿은 각각 4~8장이 필요하다. 실제 캡처 기기의 화면 비율·해상도, 앱과 APK 해시, 고정된 Git SHA 및 한국어·시간대·글자·모션 설정을 기록한다. 개인 정보와 디버그 UI가 없는지 확인한다. 사용 중인 기기의 설정과 데이터는 보존한다.

[예시 manifest](../apps/mobile/store-listing/screenshots/manifest.example.json)의 항목은 실제 캡처 값으로 채운다. 여섯 검토 항목은 담당자가 화면과 권리를 직접 확인한 뒤에만 표시한다. GitHub의 발급 workflow는 같은 사람의 검토 및 업로드, 원본 ZIP과 정확한 main SHA를 요구한다. 전체 절차는 [Play 인수 문서](PLAY_UPLOAD_HANDOFF.md)를 따른다.
